### Bug Fix -- Issue #76 (X-Frame-Options)
- Removed the no-op `<meta http-equiv="X-Frame-Options">` tag from `index.html`.
  A meta X-Frame-Options is ignored per the HTML spec and logs a Chromium console
  warning. Clickjacking protection belongs in an HTTP header at the hosting layer
  (GitHub Pages / Caddy). This also cleaned the `smoke.spec.js` "no console errors" test.
