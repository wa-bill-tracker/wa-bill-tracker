## Defects and follow-ups
- **D1 (test portability, not a prod defect on https)**: banner.spec "keyboard: Tab reaches dismiss first" and "mouse dismiss persists" fail in WebKit. Causes: (1) WebKit leaves buttons out of the Tab order by default (first Tab lands on #searchInput; Alt+Tab reaches it); (2) `CookieManager.set` writes `Secure` cookies (js/state.js, unchanged), which WebKit rejects on http://localhost, so dismissal (cookie-only, no localStorage fallback) never persists in that environment. Repro: `cd playwright && npx playwright test banner.spec.js --project=webkit`. Recommendation: serve over https or add a storage fallback for the dismissal flag, and use Alt+Tab for webkit. On https GitHub Pages dismissal should persist; unverified in real Safari.
- **D2 (labeling/data, owner decision)**: all 450 "passed" bills have `session: "2025"`; the archive has zero enacted bills with `session: "2026"` (3,307 session-2026 bills, none enacted). The page titled "Passed in 2026" therefore lists bills enacted during the 2025 session, none from 2026. Biennium text ("became law in the 2025-26 biennium") is accurate. Either rename to a biennium label or fix the archive's 2026-session statuses. Needs owner decision; I would not block ship.
- **D3 (discoverability)**: Passed in 2026 nav link is off-screen (scroll) at 1280 and 320, so the active state is also not visible when selected. Suggest scrolling it into view when active or placing it earlier. Does not block, since the empty state links to it.
- **D4 (minor)**: duplicate summary sentence in #pageDescription and #archiveStatus (role=status).
- **F2**: described under fixture assessment.
- Weak developer test: "existing prior-session tracked and notes data is left untouched" only asserts cookies exist; my spec covers exact values.
